## 3. Caveats

1. **Edge-TTS Offline Fallback**:
   - If external network access to Microsoft Edge-TTS endpoints is constrained or throttled, `TTSService` automatically cascades to `gTTS` and then to local parametric harmonic waveform synthesis (`_generate_offline_waveform`). This ensures zero runtime failure in offline or air-gapped environments.
2. **Codec Parameter Invariance**:
   - Stream copy concatenation (`-c copy`) requires that all upstream segment generators produce bitstreams with identical properties (resolution, framerate, pixel format, audio sample rate, and audio channel count). Any future segment renderer must adhere to `-pix_fmt yuv420p -r 30 -c:a aac -ar 44100 -ac 2`.
